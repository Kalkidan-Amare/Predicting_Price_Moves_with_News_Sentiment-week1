# Scripts

Command-line entrypoints for each weekly task.

- un_task1.py  Executes Task 1 EDA pipeline.
- un_task2.py  Runs technical indicator computations and plotting.
- un_task3.py  Aligns sentiment with returns and reports correlations.

Each script exposes --config for optional YAML/JSON overrides, plus task-specific flags. See python scripts/run_taskX.py --help.
