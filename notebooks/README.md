# Notebooks

Use this folder for exploratory notebooks, quick experiments, and interim visualizations. Notebook outputs should never be committed with large data cells; prefer exporting plots to eports/.

## Suggested Notebooks
- eda_news.ipynb  Task 1 textual EDA
- 	echnical_indicators.ipynb  Task 2 prototyping
- sentiment_correlation.ipynb  Task 3 deep dives

## Tips
1. Keep notebooks lightweight; move reusable code into src/.
2. Clear outputs before committing (jupyter nbconvert --ClearOutputPreprocessor.enabled=True).
3. Track decisions and insights in markdown cells for reporting.
